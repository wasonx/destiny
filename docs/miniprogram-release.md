# 甄算微信小程序发布步骤

## 当前项目结构

小程序原生代码在：

```text
miniprogram/
```

包含页面：

```text
pages/home/index          首页
pages/life/index          照见：个人节奏参考
pages/relationship/index  合缘：关系理解参考
pages/question/index      问时：事项分析参考
pages/space/index         安居：空间环境参考
pages/compass/index       罗盘：房屋朝向测量
pages/store/index         商城：报告次数包和实物产品
pages/address/index       收货地址：实物商品地址维护
pages/orders/index        订单：订单记录和退款申请
pages/report/index        报告页
pages/legal/index         协议与隐私：用户协议、隐私政策和报告分层说明
```

后端接口统一使用：

```text
https://www.goye.cc/destiny-api
```

## 发布前必须检查

1. 微信公众平台已配置 `request合法域名`：

```text
https://www.goye.cc
```

2. 微信开发者工具导入项目前，确认 `miniprogram/project.config.json` 里的 `appid` 是正式小程序 AppID：

```json
"appid": "wxc4ed7c07ce86326c"
```

3. 微信开发者工具里关闭：

```text
不校验合法域名、web-view、TLS 版本以及 HTTPS 证书
```

正式预览时必须在关闭状态下能请求接口。

## 导入微信开发者工具

1. 打开微信开发者工具。
2. 选择「导入项目」。
3. 项目目录选择：

```text
D:\Projects\destiny\miniprogram
```

4. AppID 选择正式小程序 AppID。
5. 导入后点击「编译」。

## 真机预览测试

建议至少测试：

1. 首页能看到「甄算」和五个入口。
2. 进入「照见」，填写模拟信息，能生成报告。
3. 进入「合缘」，填写双方模拟信息，能生成报告。
4. 进入「问时」，输入一个具体问题，能生成报告。
5. 进入「安居」，填写空间信息，能生成报告。
6. 进入「罗盘」，能读取方向并记录房屋朝向。
7. 进入「商城」，能看到报告次数包和实物商品。
8. 进入「收货地址」，能填写实物商品收货信息。
9. 进入「订单」，能查看订单并提交退款申请。
10. 报告页免责声明正常展示。
11. 进入「合规」，能查看用户协议、隐私政策和报告分层说明。

## 提交审核

回到微信公众平台：

```text
管理 > 版本管理 > 开发版本 > 提交审核
```

可使用以下审核说明：

```text
本版本提供个人信息录入、关系信息整理、事项问题分析、居住或办公环境建议等功能。用户可根据自身输入生成结构化生活参考报告，内容仅用于自我整理和一般生活参考。
```

测试说明：

```text
进入小程序后，可在首页选择「照见」「合缘」「问时」「安居」任一模块进行测试。填写模拟信息后点击生成报告，系统会返回结构化参考内容；也可进入「罗盘」测试房屋朝向记录，进入「商城」测试商品、收货地址、订单和退款申请。接口域名为 https://www.goye.cc，已完成 HTTPS 配置并添加至 request 合法域名。
```

## 审核通过后发布

审核通过后，在「版本管理」中点击「发布」，小程序正式上线。
