# 甄好算小程序后台填写文案

## 小程序简称

```text
甄好算
```

## 介绍

推荐版本：

```text
甄好算是一款融合东方传统文化与 AI 技术的生活参考工具，提供个人节奏、关系理解、事项分析与居住环境建议等结构化报告，帮助用户整理信息、理解选择、获得行动参考。
```

审核更稳妥版本：

```text
甄好算是一款生活信息整理与参考报告生成工具，提供个人节奏、关系理解、事项分析与居住环境建议等内容，帮助用户获得结构化生活参考。
```

## 服务类目

```text
工具 > 信息查询
工具 > 备忘录
```

## 版本描述

```text
本版本提供个人信息录入、关系信息整理、事项问题分析、居住或办公环境建议等功能。用户可根据自身输入生成结构化生活参考报告，内容仅用于自我整理和一般生活参考。
```

## 提交审核说明

```text
小程序提供「个人参考」「关系参考」「事项分析」「空间建议」等模块。用户填写相关信息后，系统会基于输入内容生成结构化生活参考报告。报告仅用于信息整理、自我探索和行动参考，不涉及医疗诊断、投资建议、法律建议，也不提供确定性预测或承诺性结论。
```

## 测试说明

```text
进入小程序后，可在首页选择任一模块进行测试。填写模拟信息后点击生成报告，系统会返回结构化参考内容。接口域名为 https://www.goye.cc，已完成 HTTPS 配置并添加至 request 合法域名。
```

## 隐私说明

```text
用户填写的信息仅用于生成本次参考报告，不会公开展示。建议用户避免填写详细门牌号、真实姓名、身份证号等敏感信息。
```

## 用词提醒

建议对外文案少用：

```text
算命、改运、预测、风水断事、保证、必然、转运
```

建议多用：

```text
参考、分析、整理、建议、结构化报告、生活参考、行动参考
```
